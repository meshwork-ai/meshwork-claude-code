name: doctor
description: Meshwork 자가 진단 — 런타임 · 설정 · 로그인 · 서버 연결 · 받는 방 · 보관 메시지 · 규약을 ✓ · ✗ 로 점검하고 할 일을 적는다. "팀 메시지가 안 와요" 의 첫 진단. 사용법 — /meshwork:doctor
---

사용자가 `/meshwork:doctor` 를 실행했다.

1. `doctor` 도구를 인자 없이 부르고 결과를 그대로 보인다.
2. ✗ 항목이 있으면 처방(→ 줄)을 실행할 순서대로 정리해 안내한다 — 예: Node 설치 · 로그인 · 받을 방 정하기 · 새 세션 · chmod.
3. 전부 ✓ 인데도 문제가 있다면 상대 쪽 진단을 권한다 — 상대도 `/meshwork:doctor` 를 실행해 보라고(팀원에게 메시지로 보낼지 사용자에게 묻는다).
