name: join
description: 초대 링크로 방에 참가한다 — 링크를 브라우저로 열어 주고, 사람이 [참가]를 누르면 이 세션이 그 방을 받는다. 사용법 — /meshwork:join <초대 링크>
argument-hint: '<초대 링크>'
---

사용자가 `/meshwork:join <초대 링크>` 를 실행했다.

1. 인자에서 초대 링크(`https://<서버>/join/…` 또는 끝의 코드)를 읽는다. 없으면 사용법을 알리고 멈춘다: `/meshwork:join <초대 링크>`
2. `join` 도구를 `{ link }` 로 부른다.
3. 결과를 그대로 보인다 — 브라우저에서 조직 · 방 · 초대한 사람을 확인하고 **[참가]를 직접 눌러야** 한다고 강조한다
   (초대는 사람이 수락해야 해서 플러그인이 대신 참가하지 않는다). 참가하면 이 세션에 「방 참가」 알림이 온다.
4. 로그인이 안 돼 있으면 먼저 `/meshwork:login` 을 안내한다. "이 서버의 초대 링크가 아닙니다" 면 링크를 보낸 사람에게 서버를 확인하라고 한다.
